Server Info

Wat is Lifesteal SMP?

Lifesteal SMP is een gamemode waarbij je harten kunt stelen van andere spelers door ze te verslaan. Als je iemand verslaat, krijg je een extra hart. Maar als je sterft, verlies je er een.

Over Titan Rise

Titan Rise is een competitieve Lifesteal SMP waar PvP centraal staat. Bouw je basis, vorm allianties of ga solo en probeer de sterkste speler op de server te worden.

Gameplay

De server draait volledig om overleven, vechten en strategie. Vertrouwen is zeldzaam — elke speler kan een vijand worden.

Doel

Het doel is simpel: word de sterkste speler door harten te verzamelen en anderen te domineren. Blijf alive, want elke dood kost je progressie.
